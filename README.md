# Yuvaraj Daily Schedule App

## Build APK in 5 Minutes (Free, No Install Needed)

### Method 1: GitHub Actions (Easiest)
1. Create free account at github.com
2. Create new repository named "schedule-app"
3. Upload ALL files from this zip
4. Go to Actions tab → "Build APK" → "Run workflow"
5. Download APK from Artifacts when done

### Method 2: Online Builder at Appetize / BuildAPKs
1. Go to https://buildapks.com
2. Upload this project zip
3. Download APK

### Method 3: Android Studio (Local)
1. Install Android Studio
2. Open this folder as project
3. Build → Generate Signed APK (or just Run)

## Install APK on Phone
1. Enable "Install from unknown sources" in Settings → Security
2. Transfer APK to phone
3. Tap APK file to install
